# Reproducibility

The manuscript figures, the test suite, and the canonical autocatalysis workflow are reproducible from this repository. This note records the commands and the expected software environment.

## Software environment

- **Python** 3.9 or later (tested on 3.9, 3.10, 3.11, 3.12).
- **NumPy** ≥ 1.22
- **SciPy** ≥ 1.8
- **Matplotlib** ≥ 3.6 (for figure scripts and the worked example)

No other runtime dependencies. The continuous-integration workflow
(`.github/workflows/ci.yml`) verifies the test suite against all four
supported Python versions on every push.

## Installation

```bash
python -m pip install -U pip
python -m pip install -e ".[viz,dev]"
```

The `[viz]` extra pulls in Matplotlib (for figures); `[dev]` pulls in
pytest, ruff, and black (for testing and linting).

## Regenerate the manuscript figures

Run from the repository root:

```bash
python scripts/figures/figure1_thermodynamic.py
python scripts/figures/figure2_mechanisms.py
python scripts/figures/figure3_finkewatzky.py
python scripts/figures/figure4_oregonator.py
python scripts/figures/figure5_benchmark.py
python scripts/figures/graphical_abstract.py
```

Outputs are written to `outputs/figures/`. Figure 4 computes the Z acceleration directly from the Oregonator ODE. Figure 5 reads `data/benchmarks/autocatalysis_operating_characteristics.csv`, the CSV generated by `scripts/si/verification_table.py`, so the SI table and Figure 5 share one numerical source of truth.

## Reproduce the Supporting-Information numerical examples

The worked example uses the same canonical autocatalysis configuration as §8.3 (n = 100, σ = 0.01 M, s = 2nσ², data seed 42, bootstrap seed 1, B = 500) and the recommended `acceleration_zero_crossing_time` detector, so the example output and the §8.3 table report the same point estimate and confidence interval:

```bash
python examples/autocatalysis_landmark.py
```

Expected output for the default seed (`rng = np.random.default_rng(42)`):

```
True inflection (theory)  : 2.5945 s
Fixed-rule estimate       : 2.4324 s
Fixed-rule 95% CI         : [2.2302, 2.6145] s
GCV estimate              : 2.5677 s
GCV 95% CI                : [2.4533, 2.6816] s
```

Minor differences (up to ~0.05 s in the point estimate and ~0.1 s in the
CI bounds) are possible with different NumPy/SciPy versions because the
underlying spline-fitting algorithm is not bit-for-bit identical across
releases. The bootstrap test in `test/test_bootstrap.py` has been
deliberately written to tolerate this drift.

## Reproduce the SI tables

The three quantitative SI tables are regenerated by committed, seeded scripts that
all share one canonical pipeline (`scripts/si/_si_common.py`): the same autocatalytic
system, the same smoothing rule `s = 2nσ²`, and the same recommended landmark
detector `acceleration_zero_crossing_time`.

```bash
python scripts/si/smoothing_table.py      # SI Sec. 7.6 (smoothing-parameter selection)
python scripts/si/bootstrap_table.py      # Sec. 8.3 (bootstrap CI)
python scripts/si/verification_table.py   # SI Sec. 9.3 (verification grid)
```

Each script prints the table it backs. `verification_table.py` also writes `data/benchmarks/autocatalysis_operating_characteristics.csv`, including Wilson binomial intervals for the Monte Carlo uncertainty in coverage and detection. `bootstrap_table.py` uses the identical seeds and detector as the Section 10 listing and the worked example, so all three agree.

## Run the tests

```bash
pytest
```

Expected output: `31 passed`.

## Determinism

- The figure scripts contain no randomness; they produce byte-identical
  PDFs across runs on the same machine.
- The worked example is seeded (`np.random.default_rng(42)` for the data,
  `seed=1` for the bootstrap). Change the seeds at the top of the file
  to explore the statistical behaviour.
- The test suite is seeded; a `pytest` run is reproducible on a given
  machine.

## Notes

- The Oregonator script uses a dense time grid to resolve stiff
  relaxation oscillations and evaluates acceleration from the model right-hand side;
  run time depends on your machine (typically 10-20 seconds).
- Generated figures are written to `outputs/figures/` and are
  intentionally **not** version controlled; the scripts create the
  directory automatically.
